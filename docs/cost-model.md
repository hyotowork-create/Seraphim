## 1. 텍스트 1건 원가

가정: 시스템 프롬프트 포함 **입력 ≈ 1,500토큰 / 출력 ≈ 3,500토큰** (기존 실측 기획 1회
≈ 합계 5,200토큰과 정합).

```
건당 USD = 1,500/1e6 × 0.30  +  3,500/1e6 × 2.50
         = 0.00045 + 0.00875
         = $0.0092  ≈  ₩12.7
```

→ **텍스트 1건 원가 ≈ ₩13.** (기획·주보·공과·스크립트·이미지 프롬프트 모두 유사)

---

## 2. 플랜별 월 원가 (텍스트만)

| 시나리오 | 월 텍스트 건수 | 월 원가(USD) | 월 원가(₩) |
|---|---|---|---|
| 라이트 개인 | 기획 3 + 부속물 15 = 18 | $0.17 | ≈ ₩230 |
| 헤비 개인 | 기획 10(한도) + 부속물 60 = 70 | $0.64 | ≈ ₩890 |
| 극단 개인 | 150건 | $1.38 | ≈ ₩1,900 |
| 교회(5좌석 공유) | 기획 30 + 부속물 320 = 350 | $3.22 | ≈ ₩4,450 |

**결론:** 텍스트 원가는 헤비 유저라도 ₩1,000 안팎. 한도(rate limit)만 걸면
적자 위험 사실상 없음 → **텍스트를 구독에 포함하는 결정은 안전.**

## 3. 구독가 마진 검증

### 개인 (가안 ₩11,900)

```
순수익 = 11,900 × (1 − 0.03) − 텍스트원가
       = 11,543 − 890(헤비)
       ≈ ₩10,653   (총이익률 ≈ 90%)
```

### 교회 (가안 ₩59,000, 5좌석)

```
순수익 = 59,000 × (1 − 0.03) − 4,450
       = 57,230 − 4,450
       ≈ ₩52,780   (총이익률 ≈ 89%)
```

→ **두 플랜 모두 텍스트 기준 총이익률 ~90%.** 이미지 원가를 구독에서 뺐기 때문에
가능한 수치이며, 이번 "이미지 분리 과금" 결정의 정당성을 수치로 확인.

> 남는 마진은 서버·DB(Supabase)·도메인·지원 인건비·환불 버퍼로 소진. 인프라 고정비는
> 사용자 수가 늘수록 1인당 희석되므로, 초기엔 90% 그대로 보지 말고 **손익분기 사용자 수**를
> 별도 산출 필요(4절).

## 4. 이미지 크레딧 단가 설계

이미지가 유일한 실질 원가 요인. **팩 판매 + 실패 자동 환불** 구조.

| 팩 | 원가(표준 $0.039) | 원가(배치 $0.0195) | 판매가(제안) | 장당 판매가 | 표준기준 이익률 |
|---|---|---|---|---|---|
| 100장 | $3.90 ≈ ₩5,380 | ₩2,690 | **₩16,000** | ₩160 | ≈ 66% |
| 300장 | ₩16,150 | ₩8,070 | **₩42,000** | ₩140 | ≈ 62% |
| 500장 | ₩26,910 | ₩13,455 | **₩65,000** | ₩130 | ≈ 59% |

설계 원칙:
- **장당 판매가 ₩130~160** — 표준 단가(₩54/장) 대비 2.4~3배로 환불 버퍼·PG수수료·마진 확보.
- 대용량 팩일수록 장당 인하 → 업셀 유도.
- **배치 API로 생성하면 원가 절반** → 실시간 필요 없는 이미지는 배치로 돌려 이익률 개선 여지.
- 크레딧 유효기간(예: 12개월) 명시 필요 — 미결정 정책.

---

## 5. 손익분기(대략)

고정비 가정(초기): Supabase Pro 약 $25/월 + 도메인·기타 ≈ 월 ₩40,000 수준.

```
개인 순이익 ₩10,653/인 기준 →  40,000 / 10,653 ≈ 유료 개인 4명이면 인프라 손익분기
```

→ **유료 개인 4~5명 확보 시 인프라 고정비 회수.** 이후는 사실상 마진.
(단, 여기엔 개발/운영 인건비 미포함 — 인건비까지 회수하려면 규모가 더 필요.)

## 6. 확정 제안

| 항목 | 제안값 | 근거 |
|---|---|---|
| 개인 월 구독 | **₩11,900** | 텍스트 원가 ~₩900, 이익률 ~90% |
| 교회 월 구독(5좌석) | **₩59,000** | 텍스트 원가 ~₩4,450, 이익률 ~89% |
| 이미지 100장 팩 | **₩16,000** | 장당 ₩160, 표준원가 대비 3배 |
| 이미지 300/500장 팩 | ₩42,000 / ₩65,000 | 장당 ₩140 / ₩130, 업셀 |
| 무료 체험 | 기획 1 + 이미지 프롬프트 1세트, 이미지 생성 0장 | 원가 노출 없이 가치 체험 |

> 남은 결정: (1) 크레딧 유효기간, (2) 연결제 할인율(관행상 2개월분), (3) 배치 API
> 도입으로 이미지 원가 절반 낮출지. 셋 다 이익률에 유리하게 열려 있음.
