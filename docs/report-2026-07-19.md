## 1. 지금까지의 결과

- **[완료]** 사업 방향 확정 — 과금모델 A+C, 개인 교사 우선→교회 확장, 텍스트 구독 포함 / 이미지 분리 과금
- **[완료]** 상세 개발 명세서 — API 설계, DB 스키마, 화면 흐름, 플랜별 한도
- **[완료]** 원가 모델 — 실단가 대입해 구독가·크레딧 팩·손익분기 검증
- **[코드 완료]** MVP 서버 골격 — DB 마이그레이션 + 서버 경유 생성 API(텍스트/이미지)
- **[미착수]** 로그인·결제·대시보드 — 카카오 로그인, PortOne 정기결제, 화면

## 2. 운용 방법 (서비스가 도는 원리)

1. **로그인** — 교사가 카카오로 로그인 (API 키 발급 불필요)
2. **서버가 대신 호출** — 우리 서버가 감춰둔 키로 AI 호출, 키는 사용자에게 안 보임
3. **한도·크레딧 검사** — 기획은 월 한도 차감, 이미지는 크레딧 선차감·실패 자동환불
4. **결과 전달·기록** — 산출물 반환 + 사용량·원가 로그 저장(정산 근거)

## 3. 실행 시 이익 (실단가 검증)

| 상품 | 가격(월) | 1인 원가 | 이익률 |
|---|---|---|---|
| 개인 구독 | 11,900원 | 약 900원 | 약 90% |
| 교회 구독(5좌석) | 59,000원 | 약 4,450원 | 약 89% |
| 이미지 100장 팩 | 16,000원 | 약 5,380원 | 약 66% |

- 텍스트 1건 원가 ≈ 13원 → 구독에 포함해도 안전
- 유일한 적자 요인인 이미지는 크레딧으로 분리 회수 → 텍스트 구독 이익률 약 90% 성립
- 인프라 손익분기: 유료 개인 4~5명 (인건비 별도)

## 4. 초기 기획 대비 달성률 — 종합 32% (정식 출시 기준)

| 단계 | 상태 | 달성 |
|---|---|---|
| 0. 검증/기획 | 완료 | 100% |
| 1. MVP 개발 | 진행 중 | 55% |
| 2. 유료 베타 | 대기 | 0% |
| 3~4. 정식/확장 | 대기 | 0% |

- 0단계: 결정·명세·원가검증 완료 (교사 인터뷰만 선택적 잔여)
- 1단계: 코드·문법검증 완료, 실 Supabase 연동·배포·동작검증 잔여
