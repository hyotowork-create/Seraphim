# Seraphim 사용 설명서

2026-09-30 · Seraphim 0.2.0

예배 송출·자막 앱 Seraphim을 처음 다루는 미디어 봉사자를 위한 안내서입니다. 예배 준비 → 송출 → 곡 관리 순서로 읽으면 됩니다.

## 1. 시작하기

설치 파일을 실행하고 데이터 폴더만 정하면 바로 쓸 수 있습니다. 계정이나 인터넷은 필요 없습니다.

### 설치

| 컴퓨터 | 파일 | 하는 일 |
| --- | --- | --- |
| 맥 (Apple Silicon) | Seraphim-0.2.0-arm64.dmg | 열어서 Seraphim을 응용 프로그램 폴더로 끌어 넣습니다. 첫 실행은 control 키를 누른 채 클릭 → 열기. |
| 윈도우 (설치형) | Seraphim Setup 0.2.0.exe | 실행하면 설치 폴더를 고르고 바탕화면 바로가기를 만듭니다. |
| 윈도우 (USB용) | Seraphim-0.2.0-portable.exe | 설치 없이 파일 하나로 실행됩니다. USB에 넣어 다니기 좋습니다. |

윈도우에서 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 한 번 누르면 됩니다. 서명 없는 앱이라 처음 한 번만 묻습니다.

### 첫 실행과 데이터 폴더

곡·성경·플레이리스트·배경 이미지는 전부 **데이터 폴더** 하나에 저장됩니다. 설정(⚙) → 데이터 저장 폴더에서 위치를 바꿀 수 있습니다.

- 다른 PC로 옮길 때는 이 폴더만 통째로 복사하고 새 PC에서 같은 폴더를 지정하면 됩니다.
- 처음 실행하면 개역한글 성경(저작권 만료본)이 자동으로 들어갑니다.
- 교회 공용 PC라면 데이터 폴더를 USB나 공유 폴더에 두어도 됩니다.

### 화면 구성

| 번호 | 패널 | 쓰임 |
| --- | --- | --- |
| 상단 | 출력바 | 송출할 모니터 선택, 출력 창 열기·닫기·전체화면, 비율(16:9 · 4:3 · 화면 채우기) |
| 1 | 라이브러리 | 곡·성경 검색과 목록, 아래쪽에 예배별 플레이리스트 |

| 4 | 빠른 기능 | 다음·이전·검정 화면·로고·일시정지, 로고 이미지 지정 |

| 7 | 오디오 | MP3 재생 |
| 8 | 전환 효과 | 페이드 켜기·끄기와 시간 |

## 2. 예배 준비: 플레이리스트

예배 하나 = 플레이리스트 하나입니다. 순서지를 붙여 넣으면 저장된 곡과 성경 본문을 찾아 자동으로 만들어 줍니다.

### 가장 빠른 방법: 순서로 만들기

1. 라이브러리 아래 플레이리스트 영역의 **순서로 만들기**를 누릅니다.
2. 한 줄에 하나씩 적습니다. 순서지를 그대로 붙여 넣어도 됩니다.
    - 성경: `요 3:16-18`, `요한복음 3장 16-18절`, `시 23편`
    - 찬송가: `478장`
    - 곡 제목: `주 하나님 지으신 모든 세계`
    - 번호·조표·메모가 섞여도 됩니다: `1. 참 아름다워라(D) – 1-3절 – 2번 연결`
3. 미리보기에서 줄마다 찾은 결과를 확인합니다. 후보가 여럿이면 고르고, 못 찾은 곡은 그 자리에서 새 곡으로 등록할 수 있습니다.
4. 확정하면 말씀 슬라이드가 저장되고 그 날짜 이름의 플레이리스트가 생깁니다.

절 범위를 적은 줄(`1-3절`)은 메모로 남아, 송출할 때 그 절만 나옵니다. 후렴은 항상 포함됩니다.

### 손으로 만들기

- 플레이리스트 영역의 **＋**로 새 플레이리스트를 만들고 이름을 적습니다.
- 플레이리스트를 열고 곡 추가 버튼으로 라이브러리에서 곡을 골라 넣습니다.
- 성경은 라이브러리 성경 섹션의 빠른 입력창에 `요 3:16`처럼 적고 Enter를 누르면 본문이 불러와지고 저장됩니다.
- 검정 화면·로고 화면도 항목으로 넣을 수 있어 기도·광고 순서를 표시해 둡니다.
- 항목은 끌어서 순서를 바꾸고, "빼기"로 냅니다.

플레이리스트는 지우지 않는 한 남아 있으므로, 지난 예배를 열어 같은 곡을 다시 쓸 수 있습니다.

## 3. 예배 중 송출

출력 창을 프로젝터로 보내 두고, 스페이스 키만 누르면 다음 자막이 나갑니다.

### 출력 창 열기

1. 프로젝터를 두 번째 모니터로 연결합니다. 맥은 시스템 설정 → 디스플레이에서 "미러링"을 끕니다.
2. 상단 출력바에서 출력 대상 모니터를 고르고 출력 창을 엽니다. 전체화면으로 띄웁니다.
3. 비율은 프로젝터에 맞춥니다. 대부분 16:9, 오래된 장비는 4:3입니다.

### 자막 넘기기

1. 플레이리스트에서 곡을 클릭하면 슬라이드 목록에 절이 카드로 나옵니다.
2. 카드를 클릭하거나 스페이스를 누르면 송출됩니다. 프리뷰에 같은 화면이 보입니다.
3. 긴 절은 한 화면 줄 수에 맞춰 여러 장으로 나뉩니다. 줄 수는 슬라이드 목록 위에서 바꿉니다.

| 키 | 동작 |
| --- | --- |
| Space | 다음 슬라이드 |
| Backspace | 이전 슬라이드 |
| B | 검정 화면 켜기·끄기 (기도·설교 중) |
| L | 로고 화면 켜기·끄기 |
| P | 일시정지. 켜 두면 실수로 눌러도 화면이 바뀌지 않음 |
| 1 / 2 / 3 | 카메라 1·2·3으로 전환 |
| + / − / 0 | 지금 나가는 카메라 줌 인 · 줌 아웃 · 원래대로 |

글자를 입력하는 칸에 커서가 있을 때는 단축키가 동작하지 않습니다. 빠른 기능 패널의 버튼으로도 같은 일을 할 수 있습니다.

### 화면 꾸미기

- **자막 스타일**(에디터): 글꼴, 크기, 글자색, 외곽선 색과 두께, 정렬, 세로 위치, 그림자. 바꾸면 바로 반영됩니다.
- **배경**(미디어): 단색, 이미지, 동영상, 라이브 카메라. "어둡게"를 올리면 밝은 배경에서도 글자가 잘 보입니다. 곡마다 다른 배경을 저장해 둘 수 있습니다.
- **로고**(빠른 기능): "이미지…"로 교회 로고 그림을 지정하면 L 키에 그 그림이 나옵니다. 지정하지 않으면 글자 로고가 나옵니다.
- **전환 효과**: 페이드와 지속 시간. 빠른 찬양은 짧게, 기도용은 길게.
- **오디오**: 특송·반주 MP3를 재생합니다.

## 4. YouTube 라이브 방송·녹화와 카메라 줌

상단의 **📡 유튜브 방송** 버튼 하나로 예배를 YouTube에 생중계하거나 녹화합니다. OBS 같은 별도 프로그램은 필요 없습니다.

### 처음 한 번 준비

1. YouTube Studio → 만들기 → 라이브 스트리밍 시작에서 "스트리밍 소프트웨어" 방식을 고릅니다.
2. 스트림 키를 복사해 방송 창의 **스트림 키** 칸에 붙여 넣고 저장합니다. 키는 이 PC에 암호화되어 보관됩니다.
3. 믹서 출력을 USB 오디오 인터페이스로 PC에 연결하고 **소리 입력**에서 고릅니다.

### 방송하기

1. **미리보기 켜기**로 나갈 화면과 소리 막대를 확인합니다.
2. **● 방송 시작**을 누르면 10~20초 뒤 YouTube Studio 미리보기에 화면이 보입니다. Studio에서 "라이브 스트리밍 시작"을 누르면 시청자에게 나갑니다.
3. 방송 중에는 상단에 빨간 **● LIVE 00:12:34**가 표시됩니다. 방송 창을 닫아도 방송은 계속되고, 이 표시를 누르면 다시 열립니다.
4. 끝나면 **방송 끝내기**를 누릅니다. 녹화 중이면 **방송만 끝내기(녹화 계속)** 또는 **방송·녹화 모두 끝내기**를 고릅니다. 방송 중에 앱을 닫으려 하면 한 번 더 묻습니다.

| 설정 | 선택지 |
| --- | --- |
| 화질 | 720p 약 3.6 Mbps(권장, 업로드 8 Mbps 이상) · 1080p 약 6.2 Mbps(업로드 13 Mbps 이상) · 1440p(2K) 약 12 Mbps(업로드 25 Mbps 이상), 모두 30fps. 아이폰 연속성 카메라는 1080p까지만 보내므로 2K에서는 자막·글자만 2K로 선명하고 카메라는 1080p를 키운 화질 |
| 방송 화면 구성 | **카메라 + 하단 자막**: 카메라 위에 작은 자막. 검정 화면(B)·로고(L)일 때는 자막만 숨기고 카메라는 계속 나감 |
| | **송출 화면 그대로**: 프로젝터 화면과 똑같이 나감 |
| 소리 | 믹서·오디오 인터페이스 입력과 크기. "소리 없음"이면 무음으로 나감 |
| 녹화 | "방송을 시작할 때 녹화도 함께 시작"(기본 켜짐). 남은 저장 공간과 녹화 가능 시간 표시 |

인터넷이 잠깐 끊기면 자동으로 다시 연결하고 경과 시간도 이어집니다. 스트림 키나 주소가 틀려 연달아 실패하면 멈추고 이유를 알려 줍니다.

### 녹화

- **상단 ● 녹화** 버튼을 누르면 방송과 상관없이 바로 녹화가 시작되고, 버튼이 빨간 **● REC 00:12:34**로 바뀝니다. 다시 누르면 녹화를 끝냅니다.
- 녹화는 방송과 따로 돌아 **인터넷이 끊겨도 한 파일로 계속** 녹화됩니다. 방송을 먼저 끝내도 녹화는 이어집니다.
- 파일은 동영상 폴더의 Seraphim 폴더에 MP4로 저장됩니다. 녹화를 끝낸 뒤 **📁** 버튼으로 바로 열 수 있습니다.
- 1시간에 720p 약 1.6GB, 1080p 약 2.7GB, 1440p 약 5.3GB를 씁니다. 남은 녹화 가능 시간이 30분 아래면 REC 표시에 남은 시간이 나오고, 10분 아래면 깜박입니다. 공간이 거의 없으면 그때까지 녹화한 부분을 저장하고 녹화를 멈춥니다.

### 카메라 1·2·3 전환과 줌

카메라는 최대 3대까지 동시에 연결해 두고 **카메라 1·2·3**으로 전환합니다. 연결된 카메라는 모두 미리 켜 두므로 전환할 때 검은 화면이 없습니다.

1. 프리뷰 아래 **카메라 칸**에서 "＋ 카메라 1"을 눌러 장치를 고릅니다. 카메라 2·3도 같은 방법입니다.
2. 카메라 칸을 누르거나 숫자키 **1·2·3**을 누르면 그 카메라로 전환됩니다. 나가는 카메라에는 빨간 테두리가 표시됩니다.
3. 프로젝터 배경([6] 미디어 → 카메라)과 유튜브 방송은 각각 **카메라 전환 따라가기** 또는 **카메라 N 고정**을 고릅니다. 예를 들어 프로젝터는 아이폰 고정, 방송은 전환 따라가기로 둘 수 있습니다.

- **줌**: 카메라마다 따로 기억됩니다. 카메라 칸 아래의 **− 1.0× +** 로 바로 줌 인·아웃하고, 배율 숫자를 누르면 원래 크기로 돌아갑니다. 좌우·상하 위치는 카메라 칸의 ⚙ 또는 [6] 미디어에서 조절합니다. 단축키 **+ − 0**은 지금 나가는 카메라에만 걸립니다.
- **아이폰**: 맥의 연속성 카메라로 연결합니다(같은 Apple ID, 가로 거치). 최대 1080p입니다.
- **DJI 오즈모 포켓 3**: USB-C로 연결하고 기기에서 "웹캠" 모드를 고릅니다. 펌웨어 v01.04.08.02 이상이면 4K까지 받아 1440p 방송에서 카메라까지 2K로 선명합니다.
- 윈도우에서는 아이폰 웹캠 앱(Camo 등)을 쓰면 일반 카메라로 보입니다.
- 디지털 줌이라 2× 이상은 화질이 조금 거칠어집니다. 크게 잡아야 하면 카메라를 가까이 두는 편이 낫습니다.
- 카메라 연결과 줌은 저장되어 앱을 다시 켜도 그대로입니다.

### 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| 서버가 방송을 받아 주지 않음 | 스트림 키를 다시 복사해 저장하고, YouTube Studio 라이브 화면이 열려 있는지 확인 |
| 방송 서버에 연결하지 못함 | 인터넷 연결을 확인하고, 교회 방화벽이 443 포트를 막는지 확인 |
| 소리 막대가 움직이지 않음 | 소리 입력 장치를 다시 고르고 믹서 출력·인터페이스 입력 볼륨을 확인 |
| "인코딩이 느림" 표시 | 화질을 720p로 낮춤 |
| 상단에 ⚠ 녹화 멈춤 | 눌러서 이유 확인. 저장 공간 부족이면 파일을 정리하고 ● 녹화를 다시 누르기 |
| 아이폰이 카메라 목록에 없음 | 아이폰 잠금 해제·가로 거치, 같은 Apple ID, 블루투스·와이파이를 켠 뒤 "새로고침" |
| 오즈모가 카메라 목록에 없음 | 기기에서 "웹캠" 모드를 고르고, 충전 전용이 아닌 데이터 전송용 USB-C 케이블로 연결 |
| 오즈모가 1080p로만 나옴 | Mimo 앱에서 펌웨어를 v01.04.08.02 이상으로 업데이트하고 방송 화질을 1440p로 설정 |

## 5. 곡 라이브러리

라이브러리에는 새찬송가 645장과 복음성가·워십이 들어 있고, 검색창 하나로 제목·장 번호·가사를 모두 찾습니다.

### 검색

| 입력 | 찾는 것 |
| --- | --- |
| `478` 또는 `478장` | 그 장 번호의 찬송가 |
| `참 아름다워라` | 제목에 그 말이 들어간 곡 |
| `하늘의 별 울려 퍼지는` | 가사 본문에 그 구절이 있는 곡. 제목이 기억나지 않을 때 |
| `마커스워십` | 작사자·팀 이름이 그런 곡 |

목록은 찬송가 장 번호 순, 그 다음 제목 순입니다. 별표를 누르면 즐겨찾기에 들어가 자주 부르는 곡을 모아 볼 수 있습니다.

### 곡 편집

곡을 더블클릭하거나 편집 버튼을 누르면 편집기가 열립니다.

- 제목, 장 번호, 카테고리(새찬송가·복음성가·워십 등), 작사자를 적습니다.
- 가사는 **빈 줄로 절을 나눕니다.** 절 처음 줄에 `1절`, `후렴`처럼 적으면 그게 절 이름이 됩니다. 적지 않으면 자동으로 번호가 붙습니다.
- **N줄마다 절 나누기**: 가사가 한 덩어리로 들어온 곡은 이 버튼으로 원하는 줄 수씩 절로 나눕니다.
- 악보에서 추출한 곡은 원본 악보 이미지가 편집기에 함께 보여, 가사를 대조하며 고칠 수 있습니다.
- **곡 삭제**는 편집기 왼쪽 아래에 있습니다. 플레이리스트에 들어 있던 자리도 함께 빠집니다.
- 같은 장 번호나 같은 제목의 곡을 저장하려면 이미 있다고 알려 줍니다.

편집기의 한글 입력은 자음·모음이 분리되지 않도록 만들어져 있습니다. 입력 중 글자가 깨지면 이 문서 마지막의 문제 해결을 봐 주세요.

## 6. 곡 넣는 방법

교회가 이미 가진 찬양 PPT·텍스트 파일을 통째로 넣거나, 악보 사진에서 가사를 읽어 들입니다. 웹에서 자동으로 긁어오는 기능은 없습니다.

### 파일 가져오기 (설정 → 곡 가져오기)

| 형식 | 읽는 방식 |
| --- | --- |
| PPTX | 파일 하나 = 곡 하나, 슬라이드 하나 = 절 하나. 중간에 글자가 큰 제목 슬라이드가 있으면 그 뒤를 새 곡으로 나눕니다 |
| TXT | 첫 줄 제목, 그 다음 가사. 빈 줄이 절 구분. `478장 참 아름다워라`처럼 쓰면 장 번호도 읽음 |
| JSON | 가사 수집 도구나 다른 프로그램에서 내보낸 목록. 가수·팀 이름은 작사자 칸에 들어감 |

1. 카테고리를 고릅니다. 장 번호가 있는 곡은 자동으로 새찬송가가 됩니다.
2. 중복 시 **건너뛰기**를 고릅니다. 같은 장 번호나 제목이 이미 있으면 들어오지 않으므로 같은 폴더를 여러 번 넣어도 안전합니다.
3. 파일이나 폴더를 선택합니다. 폴더는 하위 폴더까지 모두 읽습니다.
4. 결과에 추가·건너뛰기·실패 수가 나옵니다.

정리된 가사 모음은 `찬송가-CCM-가사-모음/1-세라핌-가져오기/` 폴더에 카테고리별 JSON으로 한 파일씩 들어 있습니다. 새 PC에서는 이 폴더만 넣으면 됩니다.

### 악보에서 가사 추출

라이브러리의 악보 버튼으로 엽니다. 사진(JPG·PNG·HEIC)이나 PDF를 여러 장 골라 넣을 수 있습니다.

| 방식 | 필요한 것 | 특징 |
| --- | --- | --- |
| Gemini (온라인) | 설정에 Google Gemini API 키 | 절·후렴 구조와 하이픈으로 늘어진 가사를 잘 읽음. 한 장에 여러 곡이 있으면 자동으로 나눔 |
| 로컬 OCR (오프라인) | 없음 | 인터넷 없는 PC용. 글자는 읽지만 절 구분이 거칠어 검수가 더 필요 |

- 사진이 작거나 흐리면 경고가 나오고 자동으로 확대해 보냅니다. 그래도 나쁘면 **정밀 모드**를 켜서 다시 합니다.
- 한 장에 여러 곡이 있으면 이미지 위를 드래그해 **영역**을 지정하면 그 부분만 읽습니다.
- 결과는 곡 탭으로 나눠 보여 주며, 제목과 가사를 고친 뒤 저장합니다. 악보 이미지는 곡에 붙어 보관됩니다.

### 유사 곡 정리

여러 출처에서 모으면 같은 곡이 제목만 조금 다르게 여러 개 생깁니다. 설정 → 유사 제목 곡 정리에서 묶음별로 남길 곡을 고르면 나머지는 합쳐지고, 플레이리스트에 들어 있던 자리는 남긴 곡으로 바뀝니다. 찬송가는 장 번호가 같을 때만 묶여 제목이 같은 다른 장이 사라지지 않습니다.

## 7. 성경 본문

구절만 적으면 본문이 불러와지고, 한 절이 슬라이드 한 장이 됩니다.

### 구절 입력

- 라이브러리 성경 섹션 빠른 입력창: `요 3:16`, `요한복음 3장 16-18절`, `시 23편`, `마 5:3-12`처럼 적고 Enter.
- 성경 편집기에서는 불러온 본문을 고칠 수 있습니다. 한 줄이 한 절입니다.
- 순서지에 적은 구절도 같은 방식으로 해석됩니다. 책 이름은 약어(창, 출, 요, 계)와 전체 이름 모두 됩니다.

### 번역본

| 번역본 | 상태 |
| --- | --- |
| 개역한글 (KRV) | 앱에 내장. 저작권이 만료된 본문이라 설치만 하면 바로 쓰임 |
| 개역개정 (NKRV) | 교회가 가진 본문 파일을 설정 → 성경 본문에서 가져와 추가. 이 맥북에는 이미 들어 있음 |

본문 파일은 텍스트·탭 구분·CSV·JSON을 읽으며, `창1:1 본문` 형식이나 열로 나뉜 형식 모두 됩니다. 기본 번역본은 성경 편집기의 번역본 선택에서 바꿉니다. 다른 PC로 데이터 폴더를 옮기면 번역본도 함께 따라갑니다.

## 8. PPTX 내보내기 · 백업 · 온라인 주보

송출 화면과 같은 모양의 PPT를 만들어 제출하거나, 데이터 전체를 zip 하나로 보관합니다.

### PPTX로 내보내기

- 플레이리스트 영역의 **PPTX** 버튼: 열려 있는 플레이리스트 전체를 순서대로 저장합니다.
- 곡 편집기의 **PPTX** 버튼: 그 곡 하나만 저장합니다.
- 화면 한 장이 슬라이드 한 장이 되고, 글꼴·크기·색·외곽선·배경·로고·비율이 그대로 들어갑니다.
- 옵션: 곡마다 제목 슬라이드, 절 라벨 표시, 배경 이미지 포함.
- 동영상·카메라 배경은 PPT에 넣을 수 없어 배경색으로 바뀝니다. 저장 결과에 그 사유가 표시됩니다.
- 제출용이면 송출 글꼴을 맑은 고딕이나 나눔고딕처럼 흔한 글꼴로 바꾼 뒤 내보내세요. 받는 PC에 없는 글꼴은 다른 글꼴로 바뀝니다.

### 백업과 복원

- 설정 → 백업 / 복원에서 **내보내기**를 누르면 DB와 미디어가 zip 하나로 저장됩니다. 예배 전보다 큰 변경 뒤에 한 번씩 받아 두세요.
- **가져오기**는 현재 데이터를 그 zip으로 덮어씁니다. 새 PC로 옮길 때 쓰면 됩니다.
- 데이터 폴더를 통째로 복사해도 같은 효과입니다.

### 온라인 주보

상단 주보 버튼에서 교회 이름, 설교 제목과 본문, 공지, 헌금 계좌를 적고, 플레이리스트를 고르면 찬양 목록이 자동으로 채워집니다. 발행하면 휴대폰 폭에 맞춘 주보 페이지가 만들어지고, 그 링크를 단톡방에 보내면 됩니다.

## 9. 문제 해결과 자주 묻는 질문

대부분은 앱을 다시 실행하거나 설정 한 군데를 바꾸면 해결됩니다.

| 증상 | 원인과 해결 |
| --- | --- |
| 출력 창이 프로젝터가 아니라 내 화면에 뜸 | 출력바에서 출력 대상을 프로젝터로 바꾸고 출력 창을 다시 엽니다. 프로젝터가 미러링이면 목록에 하나만 보이므로 미러링을 끕니다 |
| 스페이스를 눌러도 넘어가지 않음 | 검색창 등 입력칸에 커서가 있습니다. 빈 곳을 한 번 클릭하거나 일시정지(P)가 켜져 있는지 봅니다 |
| 화면이 검정으로만 나옴 | 검정 화면(B)이 켜져 있습니다. B를 다시 누릅니다 |
| 한글 입력 중 자음·모음이 따로 놂 | 입력이 끝나기 전에 다른 곳을 클릭하면 생길 수 있습니다. 마지막 글자를 친 뒤 스페이스나 Enter를 한 번 누르고 이동합니다. 그래도 생기면 어느 칸인지 알려 주세요 |
| 악보 추출이 "가사를 찾지 못함" | 사진이 너무 작거나 기울어진 경우입니다. 더 가까이서 다시 찍거나 정밀 모드를 켜고, 그래도 안 되면 영역을 지정합니다 |
| 악보 추출에서 모델 오류(404) | Gemini 모델 이름이 바뀐 경우입니다. 설정의 모델 칸에 현재 쓸 수 있는 모델 이름을 적습니다 |
| 가져온 곡이 한 덩어리로 나옴 | 원본에 빈 줄이 없던 경우입니다. 편집기의 "N줄마다 절 나누기"로 나눕니다 |
| 같은 곡이 여러 개 보임 | 설정 → 유사 제목 곡 정리로 합칩니다 |
| 윈도우에서 HEIC 악보 사진이 안 열림 | HEIC 변환은 맥에서만 됩니다. 휴대폰에서 JPG로 보내거나 맥에서 추출합니다 |
| 다른 PC에서 곡이 하나도 없음 | 데이터 폴더가 기본 위치로 되어 있습니다. 설정 → 데이터 저장 폴더를 복사해 온 폴더로 바꿉니다 |

**예배 전 점검 3가지**

1. 플레이리스트를 열고 첫 곡부터 끝까지 스페이스로 한 번 넘겨 봅니다.
2. 출력 창이 프로젝터에 전체화면으로 떠 있는지 확인합니다.
3. 글자 크기와 배경이 맨 뒷자리에서도 읽히는지 봅니다.
