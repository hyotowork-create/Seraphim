# Seraphim SaaS 전환 로드맵 (무료 → 월 구독제)

> 결정된 방향
> - **배포/과금**: 클라우드 웹앱(SaaS) + 로그인
> - **무료/유료**: 주보·PPT = 무료 / 설교 영상 쇼츠·요약 = 유료(프로 구독)
> - **출시 전략**: 초기 전 기능 무료 공개 → 이후 구독 잠금 활성화

---

## 1. 지금 구조가 어떻게 전환에 대비되어 있나

이미 **"플래그 전환"만으로 구독제가 켜지도록** 코드가 추상화되어 있습니다.

| 레이어 | 위치 | 역할 |
|--------|------|------|
| 플랜 정의 | `seraphim/plans.py` | 무료/프로 플랜, 기능별 최소 플랜, 가격(잠정) |
| 과금 모드 스위치 | `BILLING_MODE` 환경변수 | `free_launch`(전체개방) ↔ `subscription`(유료잠금) |
| 사용자 플랜 해석 | `plans._resolve_user_plan(user)` | 로그인 사용자 → 플랜 결정(현재 stub) |
| 권한 검사 | `plans.is_allowed(feature, user)` | 라우트에서 유료 기능 보호 |
| 사용자 주입 지점 | `app._current_user()` | **여기에 인증 세션만 연결하면 끝** |
| 프런트 게이팅 | `/api/plan` + 홈 카드/배지 | 잠긴 기능 🔒 표시, 402 시 업그레이드 안내 |

→ **검증 완료**: `BILLING_MODE=subscription` 으로 띄우면 쇼츠·요약 API 가
`402 Payment Required` + 업그레이드 메시지를 반환하고, 주보·PPT 는 그대로 무료.

즉 SaaS 전환 시 **새로 짜는 게 아니라 3개를 끼우면** 됩니다:
1. 인증(로그인) → `_current_user()` 가 `{'plan': ...}` 반환
2. 결제/구독 상태 → 사용자 plan 갱신(웹훅)
3. `BILLING_MODE=subscription` 으로 전환

## 2. 전환 시 추가할 구성요소

### (A) 인증 / 계정
- **추천**: 관리형 인증(Auth0 / Firebase Auth / Supabase Auth / Clerk)
  - 교회 담당자 1~2명 단위라 소셜 로그인(구글·카카오)이 편함
- 세션·JWT 를 `_current_user()` 에서 읽어 `{id, email, plan}` 반환
- 멀티테넌시: 교회(조직) 단위 계정 + 멤버 초대 구조 권장

### (B) 결제 / 구독
| 옵션 | 적합성 | 비고 |
|------|--------|------|
| **토스페이먼츠 빌링** | 국내 교회 대상 ◎ | 정기결제(빌링키), 국내 카드·간편결제 |
| 아임포트(PortOne) | ○ | 여러 PG 통합, 국내 표준 |
| Stripe Billing | 해외/구독 관리 ◎ | 국내 카드 일부 제약 |
- 구독 상태 변경은 **웹훅**으로 수신 → 사용자 plan 을 `pro`/`free` 로 갱신
- 무료 체험(14일) → 자동 구독 전환 플로우 권장

### (C) 호스팅 / 인프라
- 앱: 컨테이너(예: Cloud Run / Render / Fly.io) — 현재 Flask 그대로 배포 가능
- **영상 처리 주의**: STT(Whisper)+ffmpeg 인코딩은 CPU·시간 부담이 큼
  - 서버에서 처리하면 비용↑ → **작업 워커 분리**(현재 `jobs.py` 의 스레드를
    Celery/RQ + 별도 워커로 승격) 권장
  - 대용량 영상 업로드: 브라우저 → 오브젝트 스토리지(S3 등) presigned URL 직업로드
  - 산출물(쇼츠/PDF)도 스토리지에 저장 후 서명 URL 다운로드
- DB: 사용자·조직·구독·사용량 → PostgreSQL

### (D) 사용량 / 한도 (선택)
- 프로라도 영상 처리 분량 한도(예: 월 N시간) → `plans.py` 에 quota 필드 추가
- `jobs.py` 완료 시 사용량 적립 → 초과 시 차단/추가과금

## 3. 로컬 EXE 와의 관계

- 현재 **로컬 EXE / `python app.py`** 실행은 그대로 유지(무료 공개 기간에 유용)
- SaaS 출시 후에도 주보·PPT 는 로컬 무료 도구로 병행 배포 가능
- 단, 구독 잠금은 서버 검증이 필요하므로 **유료 기능은 SaaS(로그인) 경로 권장**

---

## 4. 단계별 실행 순서(권장)

1. **[현재] 무료 공개** — `BILLING_MODE=free_launch`, 통합 UI 로 사용자 확보
2. 클라우드 배포 + 소셜 로그인 추가 (`_current_user()` 연결)
3. 영상 워커 분리(Celery/RQ) + 스토리지 직업로드/다운로드
4. 결제(토스 빌링) + 구독 웹훅 → plan 갱신
5. `BILLING_MODE=subscription` 전환, 무료 체험 → 구독 안내 UI 노출
6. 사용량 한도·인보이스·해지 플로우 정비

---

## 5. 미정/확정 필요 항목

- [ ] 프로 플랜 **가격**(현재 `plans.py` 잠정 ₩9,900/월)
- [ ] 인증 제공자(구글/카카오 등)
- [ ] 결제 PG(토스/아임포트/Stripe)
- [ ] 영상 처리 서버 사양·비용 모델(서버 처리 vs 사용자 PC 처리 유지)
- [ ] 무료 체험 기간 및 무료 플랜 한도 정책
