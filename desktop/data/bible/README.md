# 내장 성경 본문

- `krv.tsv.gz` — 성경전서 개역한글판(1961, 대한성서공회). 저작재산권 보호기간이 2011년 말 만료되어 사용 허가 없이 쓸 수 있다(대한성서공회 저작권 FAQ). 저작인격권(성명표시·동일성유지)을 지켜 본문을 고치지 않는다. 출처: 위키문헌 정리본(github.com/Wonseong620/bible-krv), 31,102절.
- 형식: 한 줄 = `책번호(1~66)\t장\t절\t본문` (첫 줄 `#` 주석). electron-builder `extraResources`로 `Contents/Resources/bible/`에 복사된다.
- 개역개정·새번역 등 저작권이 살아 있는 번역본은 내장하지 않는다. 교회가 허가받아 보유한 본문 파일을 설정 → 성경 본문에서 가져온다.
