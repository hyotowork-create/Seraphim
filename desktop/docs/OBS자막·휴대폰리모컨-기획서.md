# 세라핌 「OBS 자막 주소」·「휴대폰 리모컨」 기획서 (초안)

> 작성 2026-11-13 · 상태: **기획만, 구현 전** · 결정 필요 항목은 맨 아래 「정할 것」
> 계기: 예배송출(worship-caster) — 작은 교회용 무료 예배 자막 앱. 기능 아이디어만 참고하고 **문구·화면·코드는 가져오지 않는다.**

## 1. 한 줄 요약

세라핌 앱 안에 **작은 로컬 웹서버 하나**를 띄워,
- **OBS 자막 주소**: OBS 「브라우저 소스」에 주소 하나만 넣으면 유튜브 생중계 화면 위에 지금 송출 중인 가사·말씀이 투명 배경 자막으로 얹힌다(캡처 장비 불필요).
- **휴대폰 리모컨·프롬프터**: 같은 와이파이의 휴대폰 브라우저로 다음·이전·검정·로고를 누르고, 설교자에게 지금·다음 슬라이드와 시계를 보여 준다(앱 설치 없음).

## 2. 왜 지금

- 작은 교회의 유튜브 중계는 대부분 「노트북 + OBS + 카메라」다. 지금 세라핌은 TV 송출 창만 있어서, 중계 화면에 자막을 넣으려면 화면 캡처·크로마키를 따로 맞춰야 한다.
- 반주자·설교자 쪽에서 직접 넘기고 싶다는 요구가 흔하고, 휴대폰은 누구나 있다.
- 비교한 예배송출에는 두 기능이 다 있다. 세라핌의 송출 기능 중 가장 큰 빈자리다.

## 3. 지금 구조에서 어디에 붙나 (코드 확인 결과)

- `src/main/index.ts`의 `liveState`가 송출 상태의 **단일 진실원**이고, `applyPatch()` → `broadcastLiveState()`가 모든 창에 보낸다. → 웹서버도 **같은 자리에서 한 줄로 구독**하면 된다.
- 다음·이전은 Control 창의 `useDeck`(렌더러)이 맡는다(`useShortcuts.ts`의 Space/⌫). → 휴대폰의 「다음」은 main이 Control 창에 IPC로 넘겨 **키보드와 똑같은 경로**로 처리한다(새 로직 없음).
- `LiveState`에는 「다음 슬라이드」가 없다. → 프롬프터용으로 `nextText`(문자열 하나)만 추가하고, `useDeck`이 넘길 때 함께 보낸다.

## 4. 기능 범위

### 1단계 — OBS 자막 주소 (먼저)
- 주소: `http://127.0.0.1:<포트>/overlay` — **이 PC 안에서만** 열림(OBS가 같은 노트북에 있으므로).
- 화면: 배경 투명, 아래쪽 자막 바(반투명 띠 + 흰 글자). 글꼴·크기·위치는 송출 설정(`OverlayStyle`)을 그대로 따르되, 「OBS용 자막 스타일」을 따로 둘지는 「정할 것」.
- 검정(B)·일시정지(P) 때는 자막을 숨긴다. 로고(L)는 중계 화면에 띄우지 않는다(기본).
- 상태 전달: 서버가 보내는 이벤트 스트림(SSE, 표준 기능) 하나. 끊기면 브라우저가 알아서 다시 붙는다.
- 앱 설정 화면에 「OBS 자막 주소 복사」 버튼과 OBS에 넣는 방법 3줄(소스 추가 → 브라우저 → 주소·1920×1080).

### 2단계 — 휴대폰 리모컨·프롬프터
- 주소: `http://<노트북 와이파이 IP>:<포트>/remote?pin=XXXX` — 설정 화면에 **QR**로 보여 준다(QR은 주보 기능의 `qrcode`를 그대로 씀).
- 리모컨 화면: 큰 단추 4개(이전 · 다음 · 검정 · 로고) + 지금 화면 글자.
- 프롬프터 화면: 지금 슬라이드(크게)·다음 슬라이드(작게)·현재 시각. 설교자 휴대폰·태블릿을 강대상에 두는 용도.
- **보안**: 같은 와이파이의 아무나 넘기지 못하게 4자리 PIN(앱을 켤 때마다 새로). PIN이 틀리면 명령을 받지 않는다. 리모컨은 설정에서 켤 때만 외부(와이파이) 주소로 열고, 기본은 꺼짐.

### 하지 않는 것
인터넷 너머 원격 조종(같은 와이파이만), 휴대폰 앱 설치, 여러 대 동시 조종 충돌 처리(마지막 누른 것이 이김), 자막 디자인 편집기, 웹에서 곡·성경 편집(예배송출의 「웹 편집기」는 이번 범위 밖).

## 5. 구현 메모(작게)

- 새 의존성 없음: Node 기본 `http` 모듈 + SSE. 페이지 두 개는 정적 HTML 한 장씩(앱 안에 포함, 인터넷 없이 동작 — 글꼴은 앱 것 사용).
- main: `src/main/remote.ts` 한 파일(서버 시작·종료, `/overlay`·`/remote`·`/events`·`/cmd`), `broadcastLiveState()`에서 SSE로도 보냄.
- 포트: 기본 하나(예: 47200), 쓰는 중이면 다음 번호. 설정 화면에 실제 주소 표시.
- 방화벽: 윈도우·맥이 처음 한 번 「허용」을 묻는다 → 설치 안내에 한 줄 추가(OBS 주소는 127.0.0.1이라 리모컨을 켤 때만 물음).
- 점검: `/cmd`가 PIN 없이 거절되는지, SSE가 상태 변경 1회에 1번 오는지 작은 테스트 하나.

## 6. 순서와 대략 작업량

| 단계 | 내용 | 대략 |
|---|---|---|
| 0 | 맥 최신 세라핌 코드(0.2.0~0.3.1 실제 소스)를 GitHub에 올림 — **교회 행정 기획서와 같은 전제** | 운영자 5분 |
| 1 | OBS 자막 주소 + 설정 화면 복사 버튼·안내 | 작음 |
| 2 | 휴대폰 리모컨·프롬프터 + PIN + QR + `nextText` | 중간 |

끝 기준: 실제 OBS(맥·윈도우 각 1회)에서 자막이 투명하게 얹히고, 휴대폰(아이폰·안드로이드 각 1회)으로 넘김이 1초 안에 TV·OBS 둘 다에 반영.

## 7. 정할 것

- [ ] 0단계: 맥 최신 세라핌 브랜치 push(교회 행정과 공통)
- [ ] OBS 자막을 TV 송출 스타일과 **같게** 할지, 중계용 스타일(아래 띠·작은 글씨)을 **따로** 둘지 — 권장: 따로(중계 화면은 아래 띠가 일반적)
- [ ] 리모컨 PIN을 매번 새로 만들지, 고정할지 — 권장: 매번 새로(QR로 들어가면 입력할 일 없음)
- [ ] 1단계만 먼저 낼지(작고 효과 큼), 1·2단계를 한 번에 낼지
- [ ] 시험할 교회 장비(OBS 버전, 휴대폰 기종)
