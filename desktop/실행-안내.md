# Seraphim 실행 안내 (창 띄우기)

앱 창은 **사용하는 PC에서 직접 실행**해야 뜹니다. (클라우드/원격에서는 창이 뜨지 않습니다.)

## 가장 쉬운 방법 — 더블클릭

1. **Node.js LTS** 설치 (한 번만): https://nodejs.org
2. `desktop` 폴더에서
   - **Windows**: `Seraphim 실행하기.bat` 더블클릭
   - **macOS**: `Seraphim 실행하기.command` 더블클릭
3. 처음 1회는 자동으로 설치가 진행됩니다(인터넷 필요, 몇 분).
   설치가 끝나면 **운영자(Control) 창**이 뜹니다.
4. 상단 **송출 열기** 버튼으로 프로젝터(Output) 창을 띄웁니다.

> 검은 명령창은 앱이 켜져 있는 동안 닫지 마세요. 앱을 끄면 같이 닫으면 됩니다.

## 개발자용 (터미널)

```bash
cd desktop
npm install       # 처음 1회
npm run rebuild   # 처음 1회 (SQLite 네이티브 모듈)
npm run dev       # 실행
```

## 설치본 / USB Portable 만들기 (배포용)

Windows 설치본(.exe)과 USB Portable은 **Windows PC에서** 만듭니다:

```bash
cd desktop
npm install
npm run build:win        # 설치본(NSIS) + Portable 동시
# 결과물: desktop/release/
```

- 설치본: `Seraphim Setup x.y.z.exe` — 더블클릭 설치
- Portable: `Seraphim-x.y.z-portable.exe` — 설치 없이 USB에서 바로 실행

macOS 앱(dmg)은 macOS에서 `npm run build:mac` 으로 만듭니다.

## 첫 사용 순서

1. ⚙️ **설정** → 데이터 저장 폴더 지정 (구글드라이브/드롭박스 폴더로 하면 여러 PC 공유)
2. `+ 새 곡` 으로 가사 입력, 또는 `악보` 로 악보 사진에서 가사 추출(설정에 Gemini API 키 필요)
3. 곡 선택 → **Space**로 송출, `B` 검정 / `L` 로고 / `P` 일시정지
4. 📰 **주보 발행** 으로 온라인 주보 생성
