교회학교 설교·자료 제작

부서를 고르고 본문을 넣으면, 부서 눈높이에 맞춰 설교 기획·이미지·주보·공과까지 만듭니다. 슬라이드는 ②제작 탭에서 PPTX로 묶습니다.

model: gemini-3-pro-image-preview

연결 · 모델

기획 단계는 텍스트 모델 + 구글 검색을 사용합니다(이미지 모델과 별개).

교회학교 부서

부서를 고르면 눈높이·트렌드 대상·이미지 톤·산출물 분량이 자동 전환됩니다.

산출물 유형

만들 자료를 고르세요. 유형에 따라 ②단계 생성 버튼이 바뀝니다. 슬라이드는 제작 탭에서 PPTX로, 주보·공과는 텍스트로 나옵니다.

이미지 톤

슬라이드용 이미지 스타일. 부서에 맞는 후보만 표시됩니다.

설교 본문

장절을 입력하세요. 예: 마가복음 4:35-41

설교 기획안 (설교자 검토·수정)

트렌드·눈높이 풀이·설교 포인트·개요·봉독이 여기 나옵니다. 직접 고친 뒤 다음 단계로 넘기세요.

② 산출물 생성

검토한 기획안을 바탕으로 선택한 산출물을 만듭니다.

연결 설정

Google AI Studio의 API 키를 붙여넣으세요.

약간 수정

모든 프롬프트에 공통으로 덧붙일 지시문입니다(스타일·톤·일관성).

구분 방식

붙여넣은 텍스트를 어떻게 개별 프롬프트로 나눌지 선택합니다.

슬라이드 출력

생성된 이미지를 순서대로 PPTX로 묶습니다. 각 카드의 ‘슬라이드 글자’는 편집 가능한 텍스트로 얹힙니다. 제목형은 금색 외곽선·글로우 큰 글씨(제목·헌금기도·축도), 말씀형은 첫 줄=금색 장절, 다음 줄부터=흰색 본문(봉독)으로 나옵니다. ‘자동’이면 장절(장·절·:)이 보이면 말씀형, 아니면 제목형으로 판단합니다.

배경은 카드에서 ‘제목 배경으로 지정’한 이미지를 자동 사용합니다(지정 안 하면 단색).

프롬프트 입력

제미나이가 만들어준 이미지 프롬프트 전체를 그대로 붙여넣으세요.
