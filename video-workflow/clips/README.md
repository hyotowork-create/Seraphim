# clips/ — 여기에 클립을 넣으세요

HappyHorse(STAGE 2)로 만든 클립을 이 폴더에 저장합니다.

- 이름: `clip01.mp4`, `clip02.mp4`, … (숫자 두 자리 권장 — 정렬이 안전)
- 확장자: `.mp4 .mov .m4v .webm .mkv` 지원
- 개수·길이 제각각이어도 됩니다 (STAGE 3가 자동으로 60초로 맞춤)

넣은 뒤 상위 폴더의 `영상_합치기.command`(Mac) / `영상_합치기.bat`(Windows)를
더블클릭하면 `output/final_60s.mp4` 가 만들어집니다.
