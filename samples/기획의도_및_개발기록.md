## 1. 원래 기획 의도 (최초 요청 원문)

> 교회 방송실 업무 자동화할 웹앱 개발예정이야. **EXE기반으로 실행**할 수 있어야 해.
> 찬양악보와 설교본문을 입력하면, **깔끔하고 세련된 디자인의 찬양 PPT**와 **설교제목**,
> **html기반의 주보 템플릿**에 제목과 본문이 입력되고, **광고내용도 별도 입력**하면
> **광고 슬라이드와 광고내용이 주보에 입력**될 수 있도록 코드를 작성해서 제출해.

### 핵심 요구사항 정리

| # | 요구사항 | 비고 |
|---|----------|------|
| 1 | 교회 방송실 업무 자동화 **웹앱** | 방송실 담당자가 매주 반복하는 PPT·주보 제작을 자동화 |
| 2 | **EXE 기반 실행** | 별도 설치·서버 없이 방송실 PC에서 더블클릭 실행 |
| 3 | 찬양악보(가사) 입력 → **세련된 찬양 PPT** 생성 | 무대 스크린에 바로 띄울 수 있는 깔끔한 디자인 |

## 2. 기획 해석 및 설계 방향

방송실 실무는 매주 **같은 양식**에 내용만 바꿔 PPT와 주보를 새로 만드는 반복 작업이다.
이를 **"한 화면에서 내용만 입력 → PPT·주보 동시 생성"** 흐름으로 자동화하는 것이 목표였다.

### 기술 스택 결정

| 영역 | 선택 | 이유 |
|------|------|------|
| 웹 UI / 서버 | **Flask (Python)** | 가볍고 로컬 단독 실행에 적합 |
| 찬양·설교·광고 PPT | **python-pptx** | PowerPoint 설치 없이 .pptx 직접 생성 |
| HTML 주보 | **Jinja2 템플릿** | 인쇄용 A4 레이아웃, 브라우저 PDF 저장 |
| EXE 패키징 | **PyInstaller (--onefile)** | 단일 실행 파일, 더블클릭 실행 |

→ 단일 Python 스택으로 "웹앱 + EXE + PPT + HTML 주보" 모든 요구를 충족.
→ EXE 실행 시 기본 브라우저가 자동으로 열리도록 진입점 구성.

## 3. 구현 결과 (기능 ↔ 요구사항 매핑)

| 요구사항 | 구현 결과 |
|----------|-----------|
| EXE 기반 실행 | `build_exe.py` (PyInstaller onefile) → `Seraphim.exe`, 실행 시 브라우저 자동 오픈 |
| 찬양 PPT | 곡별 표지 + 가사 슬라이드 자동 생성. **빈 줄로 절(슬라이드) 자동 분할**, 16:9 와이드, 그라데이션 배경 |
| 설교 슬라이드 | 설교 제목·본문(성경구절)·설교자 표지 슬라이드 |
| 광고 슬라이드 | 입력한 광고를 항목별 슬라이드로 생성 |
| HTML 주보 | 설교·찬양·광고가 채워진 인쇄용 A4 주보 (Ctrl+P → PDF) |
| 광고 동시 반영 | 광고 1회 입력 → PPT 광고 슬라이드 + 주보 광고란 양쪽 자동 반영 |
| 추가 | 디자인 테마 5종, 실시간 주보 미리보기 |

### 생성 예시 (샘플 입력 → 12슬라이드 PPT)

```
 1. 예배 표지 (세라핌교회 · 주일 낮 예배)
 2~5. 찬양 ①「주 은혜임을」 표지 + 가사 3장
 6~8. 찬양 ②「은혜」 표지 + 가사 2장
 9.  설교 표지 (사랑 안에 거하라 · 요한일서 4:16)
10.  광고 표지
11~12. 광고 슬라이드 2장 (야외예배 / 새가족 환영회)
```

## 4. 채팅 진행 내역 (개발 로그)

### ① 최초 요청 — 웹앱 개발
- 위 기획 의도 전달, "코드를 작성해서 제출" 요청
- **수행**: 저장소 확인(README만 존재) → Python 3.11 / Node 22 환경 확인
  → Flask + python-pptx + Jinja2 + PyInstaller 스택 결정
- **구축 파일**:
  - `app.py` — Flask 서버 + EXE 진입점(브라우저 자동 실행)
  - `seraphim/ppt_generator.py` — 찬양/설교/광고 PPT 생성
  - `seraphim/bulletin.py` — HTML 주보 생성
  - `seraphim/themes.py` — 디자인 테마 5종
  - `templates/`, `static/` — 입력 UI + 주보 템플릿 + 실시간 미리보기
  - `build_exe.py` — EXE 빌드 스크립트
  - `test_pipeline.py` — 스모크 테스트
- **검증**: 테스트 전체 통과(10슬라이드 생성), 4개 API 정상 응답 → 커밋·푸시

- **수행**: 서버 실제 기동 → 샘플 예배 데이터로 PPT(12슬라이드)·주보 생성
- 슬라이드 구성·주보 내용 검증 후 실제 파일을 채팅으로 전달
